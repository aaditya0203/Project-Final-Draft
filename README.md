# 🏗️ Constructify

## AI-Based Construction Activity Tracking System

Constructify is an AI-powered system for monitoring building construction progress using Computer Vision and Machine Learning.

---

## ✨ Features

- Construction Site Image Upload
- AI-Based Progress Detection
- Structural Change Analysis
- Real-Time Monitoring
- Interactive Dashboard
- Automated Reporting

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Python | Backend Logic |
| OpenCV | Image Processing |
| CNN | Progress Detection |
| React + TypeScript | Frontend |
| Streamlit | Dashboard |

---

## ⚙️ Installation

```bash
git clone https://github.com/aaditya0203/Project-Final-Draft.git

cd Project-Final-Draft

pip install -r requirements.txt

streamlit run app.py
```
